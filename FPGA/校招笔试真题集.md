## 一、经典高频笔试题（各公司反复考，含解析）

### 1.1 建立时间计算与最高频率（⭐⭐⭐⭐）

**知识点**：`setup/hold`、`时序`

**题干**：两级触发器之间组合逻辑最大延迟 4ns，触发器 $t_{co}=1\text{ns}$、$t_{su}=1\text{ns}$、$t_h=0.5\text{ns}$，时钟周期 10ns，忽略 skew。问：是否违例？最高工作频率？

**答案**：不违例；$f_{max} \approx 166.7\text{MHz}$。

**解析**：
$$T_{min} = t_{co} + t_{comb} + t_{su} = 1+4+1 = 6\text{ns} \le 10\text{ns} \text{ ✓}$$
$$f_{max} = 1/T_{min} = 1/6\text{ns} \approx 166.7\text{MHz}$$
hold 检查：$t_{co(min)} + t_{comb(min)} \ge t_h$，与频率无关，只要路径最小延迟够即可（一般组合路径最小延迟 ≥ 0）。

### 1.2 阻塞/非阻塞赋值结果（⭐⭐⭐）

**知识点**：`Verilog`、`阻塞/非阻塞`

**题干**：初始 $a=1,b=0$，上升沿后下面两段代码 $a,b$ 分别是什么？

```verilog
// 代码1
always @(posedge clk) begin
    a <= b;
    b <= a;
end
// 代码2
always @(posedge clk) begin
    a = b;
    b = a;
end
```

**答案**：代码1 → $a=0,b=1$（交换）；代码2 → $a=0,b=0$。

**解析**：非阻塞 `<=` 并行取旧值，所以 a 拿 b 旧值 0、b 拿 a 旧值 1，交换；阻塞 `=` 顺序执行，a 先变 0，b 再取"已经变过的 a"=0。**时序逻辑里用阻塞赋值会仿真/综合不一致**，这是经典反例。

**追问（高频变体：同一块内混用 `<=` 和 `=`）**：下面代码在上升沿后 $a,b$ 是多少？

```verilog
always @(posedge clk) begin
    a <= in + 1;
    b = a;
end
```

**答案**：$a = in+1$（本拍新值）；$b$ 得到的是 **a 的旧值**（上一拍的值）——即 b 恰好比 a 晚一拍。

**解析**：关键不在符号本身，而在**"读 a 的那一刻，a 更新了没有"**：

- `a <= in + 1` 非阻塞：右边 $in+1$ 先算好，但 **a 的更新推迟到本时间步末尾**统一进行；
- `b = a` 阻塞：**当场执行**，此刻 a 还停在旧值（更新尚未发生），所以 b 读到的是旧值。

举例：沿到来前 $a=3$、$in=5$ → 沿后 $a=6$、$b=3$；下一拍 b 继续拿这一拍的 a，稳定保持"b 比 a 晚一拍"。

三种写法对比（同一沿之后）：

| 写法 | $a$ | $b$ |
|------|-----|-----|
| 混合 `a <= in+1; b = a;` | $in+1$ | a 的旧值 |
| 全阻塞 `a = in+1; b = a;` | $in+1$ | $in+1$（新值，与 a 同值） |
| 全非阻塞 `a <= in+1; b <= a;` | $in+1$ | a 的旧值 |

混合写法**结果恰好与全非阻塞相同**，但仍是风格大忌：工具链（综合/lint）普遍会报 "mixed blocking and non-blocking" 类警告，且 b 先于 a 在时间步内更新，容易与其他块产生竞争。面试标准答法：**时序一律 `<=`、组合一律 `=`，绝不混用**（对比表见 [[FPGA/FPGA校招面试八股.md|八股]] 2.2 节）。

### 1.3 FIFO 深度计算（⭐⭐⭐⭐⭐）

**知识点**：`FIFO 深度`、`CDC`

**题干**：写时钟 100MHz 背靠背突发写 200 个数据，读时钟 80MHz 连续读，问 FIFO 最小深度。

**答案**：40。

**解析**：突发时长 $T = 200/100\text{M} = 2\mu\text{s}$，期间读走 $80\text{M}\times2\mu\text{s}=160$ 个，深度 $=200-160=40$。公式见 [[FPGA/FPGA校招面试八股.md|八股]] 7.2 节。

### 1.4 占空比 50% 的三分频（⭐⭐⭐⭐）

**知识点**：`分频`、`Verilog`

**题干**：写出占空比 50% 的三分频器代码。

**答案**：模 3 计数器，上升沿/下降沿各产生 `(cnt==0)` 脉冲，相或：

```verilog
reg [1:0] cnt_p, cnt_n;
always @(posedge clk or negedge rst_n)
    if (!rst_n) cnt_p <= 0; else cnt_p <= (cnt_p==2)?0:cnt_p+1;
always @(negedge clk or negedge rst_n)
    if (!rst_n) cnt_n <= 0; else cnt_n <= (cnt_n==2)?0:cnt_n+1;
assign clk_out = (cnt_p==0) | (cnt_n==0);
```

### 1.5 推断出 latch 的代码（⭐⭐⭐）

**知识点**：`Verilog`、`latch`

**题干**：下面代码综合出什么电路？

```verilog
always @(*) begin
    if (en) y = d;
end
```

**答案**：推断出 **latch**（en=0 时 y 保持）。

**解析**：组合 always 中 `if` 无 `else` → 未写分支保持旧值 → 综合器用锁存器实现。应补 `else y = 1'b0;`。

### 1.6 跨时钟域单比特处理（⭐⭐⭐）

**知识点**：`CDC`

**题干**：慢时钟域的单比特电平信号传到快时钟域怎么处理？快→慢的窄脉冲呢？

**答案**：慢→快：打两拍即可；快→慢：窄脉冲可能短于慢周期而漏采，需**脉冲同步器（toggle 法）**或**展宽+握手**。详解见 [[FPGA/FPGA校招面试八股.md|八股]] 4.2 节。

### 1.7 序列检测 1011（⭐⭐⭐⭐）

**知识点**：`状态机`、`FSM`

**题干**：设计可重叠的 1011 序列检测器（Moore），画出状态转移关系。

**答案**：$S_0 \xrightarrow{1} S_1 \xrightarrow{0} S_2 \xrightarrow{1} S_3 \xrightarrow{1} S_4$（$S_4$ 输出 1）；重叠：$S_4 \xrightarrow{1} S_1$、$S_4 \xrightarrow{0} S_2$。完整代码见 [[FPGA/FPGA校招面试八股.md|八股]] 6.4 节。

**1. 时钟 jitter 和时钟偏斜的概念，以及它们影响 FPGA 的最高工作频率吗？（⭐⭐⭐⭐）**

**知识点**：`skew`、`jitter`、`时序`

**答案**：
- **时钟偏斜 skew**：同一时钟源到达**不同触发器**的时间差。根源是时钟布线长度不同（走线有延迟），所以"同一个沿"到 A 触发器和 B 触发器时刻不一致。它是**空间（芯片位置）维度的偏差**。
- **时钟抖动 jitter**：时钟边沿相对理想时刻的**随机偏差**。根源是 PLL/MMCM 的相位噪声、电源纹波、温度漂移。它是**时间（同一位置不同时刻）维度的不确定**，同一时刻看单个 FF 的沿也在抖。

**它们影响最高频率吗？—— 都影响**，机理不同：

| 因素 | 对 setup 的影响 | 对 hold 的影响 | 净效果 |
|------|----------------|---------------|--------|
| skew（负偏斜，接收端时钟**早到**） | 吃掉建立余量 | 有利于保持 | **降低**最高频率 |
| skew（正偏斜，接收端时钟**晚到**） | 增加建立余量 | 威胁保持 | 可能提高 setup 上限，但 hold 变紧 |
| jitter | 压缩有效周期 | — | 一定**降低**最高频率 |

setup 分析公式（保守把 skew/jitter 都加进去）：
$$T_{clk} \ge t_{co} + t_{comb} + t_{su} + t_{skew} + t_{jitter}$$

**符号含义**（记忆：沿 1 出发 → 传数据 → 赶在沿 2 前稳定，一共只有 $T_{clk}$）：

| 符号 | 全称 | 含义 |
|------|------|------|
| $T_{clk}$ | 时钟周期 | 倒数即最高频率 $f_{max}=1/T_{clk}$ |
| $t_{co}$ | clock-to-output | 发送触发器的输出延迟：时钟沿到后 Q 端出数据的时间 |
| $t_{comb}$ | 组合逻辑延迟 | 数据穿过中间所有 LUT/布线的总延迟 |
| $t_{su}$ | 建立时间 | 接收触发器要求数据提前于时钟沿稳定 |
| $t_{skew}$ | 时钟偏斜 | 时钟到收发两个触发器的时间差（空间偏差） |
| $t_{jitter}$ | 时钟抖动 | 时钟沿随机偏差，等效压缩周期（时间偏差） |

**时间线**：时钟沿 1 →（$t_{co}$）发送 FF 输出 →（$t_{comb}$）组合逻辑 → 接收 FF 的 D 端 → 须在时钟沿 2 前 $t_{su}$ 稳定；沿 1→沿 2 总长 $T_{clk}$，再留 skew/jitter 余量。

所以**结论：都会影响最高工作频率**。jitter 只有坏影响；skew 方向不定，设计按最坏情况处理。**回答要点**：先把两者概念讲清（空间 vs 时间），再分别说它们怎么进时序公式。

**2. 建立时间和保持时间的概念，以及出现违例怎么修复？（⭐⭐⭐⭐⭐）**

**知识点**：`setup/hold`

**答案**：
- **建立时间 $t_{su}$**：时钟沿**到来前**，数据必须提前稳定下来的最小时间。它限制了数据能"走多慢"。
- **保持时间 $t_h$**：时钟沿**到来后**，数据必须继续保持不变的最小时间。它限制了数据能"变多快"。

**setup 违例**（数据到得太晚）——**影响：限制最高工作频率**（路径太长，数据来不及在下一个沿前稳定，频率一高就出错，所以"最高频率上不去"）。修复：
1. **降频**（增大 $T_{clk}$），最直接；
2. **插流水线**：在组合路径中间切一级 FF，把 $t_{comb}$ 切成两半（面积换速度）；
3. **逻辑优化**：减少组合级数、把大表达式拆小、用查找表替换；
4. **综合/布局优化**：提高综合 effort、约束布局、寄存器重定时 retiming；
5. 减小 skew。

**hold 违例**（数据变得太快）——**影响：功能性错误，与频率无关**（数据在同一个时钟沿后没保持住 $t_h$，接收端采到的是"变掉的值"，即使降频也照样错）。修复：
1. **数据路径加 buffer 延迟**（在布线工具里加 delay cell / buffer）；
2. 工具里开 hold 修复选项；
3. 注意：**hold 与频率无关**，降频救不了 hold 违例——因为 hold 检查的是"同一个沿后数据不能马上变"，时钟周期再大也没用。

> **插 buffer 是什么？和"打拍"有什么区别？（面试高频追问）**
>
> **打拍** = 在路径上插入**触发器 FF**（有时钟）：把组合路径切短，数据**晚一个时钟周期**到 → 修 **setup 违例**。
> **插 buffer** = 在路径上插入**延迟单元**（如两个反相器串联的 buffer，无时钟）：加一点**纯传播延迟** $\Delta t$，数据**慢几纳秒**到、不多占周期 → 修 **hold 违例**。
>
> 一句话：**打拍=加停顿站（修 setup，但加 1 拍延迟）；插 buffer=加绕路（修 hold，只吃面积/时序余量）**。二者不能互换——打拍对 hold 无效，插 buffer 反而恶化 setup。FPGA 中 hold 一般由布线工具自动修复，不必手插。

判断违例看 **timing report 的 WNS/TNS**（负值即违例）。

**3. BRAM 和分布式 RAM 的区别？什么情况优先选哪个？（⭐⭐⭐⭐）**

**知识点**：`BRAM`、`分布式 RAM`

**答案**：

| 对比项 | BRAM | 分布式 RAM |
|--------|------|------------|
| 物理实现 | 专用硬核存储块（7 系每块 36Kb） | 用 **LUT** 拼出来的存储 |
| 容量 | 大（几 Kb～几十 Mb） | 小（几十 bit～几 Kb） |
| 读写 | 同步写、同步读（有寄存器输出，读延迟固定 1~2 拍） | 同步写、**可异步读**（也可同步） |
| 资源成本 | 占专用 BRAM 块 | 占 LUT/FF（与逻辑争资源） |
| 端口 | 每块有限（一般 2 端口） | 灵活，可拆成多个小端口 |
| 时序 | 时序友好，不占逻辑资源 | 容量大时占用 LUT 多、时序变差 |

**选择原则**：
- **大容量、规整、需要同步读的存储**（数据缓冲、图像行缓存、跨时钟 FIFO 体）→ **BRAM**；
- **小容量（≤ 几 Kb）、需要异步读、或 BRAM 已用尽** → 分布式 RAM；
- **小移位寄存器 / 小 FIFO / 延迟线** → 分布式（SRL16 就是 LUT 改的移位寄存器）；
- **海量小存储分散在逻辑中** → 分布式更省 BRAM。

一句话：**大而规整用 BRAM，小而灵活用分布式**。

**4. IOBUF、IDELAY、IDDR、ODDR 是什么？应用场景？（⭐⭐⭐⭐）**

**知识点**：`IO 原语`

**答案**：

| 原语         | 全称/作用      | 关键点                                       | 应用场景                                         |
| ---------- | ---------- | ----------------------------------------- | -------------------------------------------- |
| **IOBUF**  | 双向 IO 缓冲器  | 三态控制（高阻 Z / 输出 / 输入），一个 pin 双向            | I2C 的 SDA、存储器数据线等 **inout 总线**               |
| **IDELAY** | 输入可编程延时单元  | 对输入信号做精细延时（步进几十 ps，由 tap 控制）              | 对齐源同步接口的 **per-bit skew**（DDR 数据线、LVDS 串行数据） |
| **IDDR**   | 输入 DDR 寄存器 | 时钟**上、下沿各采 1 bit**，把 1 路 DDR 转成 2 路并行（半速） | DDR 接口**接收**，如 DDR3/4 数据读                    |
| **ODDR**   | 输出 DDR 寄存器 | 把 2 路并行数据在**上、下沿分别输出**，合成 1 路 DDR         | DDR 接口**发送**、DDR 时钟输出（如 DQS 发射）              |

**串联一句话**：**IDDR/ODDR 负责串并/并串转换（DDR 收发）**，IDELAY 负责输入对齐（解决源同步接口的 bit-skew），IOBUF 负责双向总线。写 DDR 接口或高速源同步接口时这四样是标配。

**5. 竞争和冒险的概念、怎么判断、怎么消除？（⭐⭐⭐⭐）**

**知识点**：`竞争冒险`

**答案**：
- **竞争（race）**：同一信号经**不同路径**（不同门延迟）到达汇合门，各路径延迟不同，到达时刻不一致。
- **冒险（hazard）**：竞争导致输出出现**违背稳态逻辑的瞬时毛刺**。分两类：
  - **静态 1 冒险**：输出本应恒 1，却瞬时掉到 0（负脉冲），对应 $Y=X+\overline{X}$ 形式；
  - **静态 0 冒险**：输出本应恒 0，却瞬时跳到 1（正脉冲），对应 $Y=X\cdot\overline{X}$ 形式。

**判断（三种方法）**：
1. **代数法**：把其余变量代入固定值，若表达式能化成 $X+\overline{X}$ → 1 型冒险；化成 $X\overline{X}$ → 0 型冒险。
2. **卡诺图法**：两个积项圈**相切不相交**处，就是冒险点。
3. **波形观测**：示波器/仿真看跳变瞬间是否出现毛刺。

**消除（四种手段 + 原理）**：
| 手段 | 原理 |
|------|------|
| 加**冗余乘积项** | 桥接相切圈，过渡期托住输出（最治本） |
| 输出**并联电容** | 低通滤掉窄毛刺（低速可用） |
| **选通脉冲** | 避开瞬态，只采稳态 |
| **输出加同步寄存器** | 时钟沿屏蔽沿间毛刺——**FPGA 最常用** |

**6. reg 和 wire 区别？reg 不赋初值综合后电路什么样？（⭐⭐⭐）**

**知识点**：`Verilog`

**答案**：
- **wire**：线网类型，由 `assign` 或模块端口连续驱动，表示物理连线。
- **reg**：变量类型，由 `always` 块过程赋值。**关键：reg 不一定是寄存器**——
  - `always @(posedge clk)` 里的 reg → 综合成**寄存器（FF）**；
  - `always @(*)` 里的 reg → 综合成**组合逻辑**；
  - 组合 always 里 if/case 分支不全 → 综合成 **latch**。

**不赋初值综合后**：
- 仿真中：reg 默认是 **X**，参与运算会把 X 传染。
- 综合后上电：寄存器的初始状态是**随机的/不定**（取决于 FPGA 配置后 FF 的实际状态）。
- **后果**：计数器/状态机可能从任意状态起跑 → 表现为"随机复位/数据错误"。
- **对策**：**必须复位初始化**——异步复位、同步释放，或复位时赋初值。这是"随机复位/数据错误"类问题的第一大嫌疑。

**7. case 有 default 的好处？没有 default 综合会怎样？（⭐⭐⭐）**

**知识点**：`Verilog`

**答案**：
- **default 的好处**：
  1. 覆盖未列举的编码，**避免推断出 latch**（组合 case 未穷举时保持旧值）；
  2. 状态机的**非法状态有去处**（归到 IDLE），防止跑飞；
  3. **仿真与综合一致**（未加 default 时两者行为可能不同）。
- **没有 default**：
  - 组合 case 未穷举（如 2bit 只写 00/01/10 三支）→ 综合推断出 **latch**（那支保持旧值）；
  - 用于 FSM → 未定义编码没有转移，可能**进入非法状态**无法跳出。
- **建议**：每个 case 都写 default，即使已穷举（1bit 的 0/1）也写上，更安全、语义更清楚。

**8. 复杂 FPGA 项目随机复位/数据错误、无法复现，用什么方法/工具定位？（⭐⭐⭐⭐⭐）**

**知识点**：`Debug`、`CDC`

**答案**：随机、无法复现的错误，99% 与**异步/跨时钟/复位**有关，按"在线抓 → 工具扫 → 根源查 → 仿真复现"四步排查：

1. **在线抓信号（不打断运行）**：加 **ILA**（Vivado 逻辑分析仪核）抓关键信号——复位、PLL lock、FIFO 空满、状态机当前态、数据使能、错误标志；**VIO** 在线读写内部寄存器，现场注入/查询。
2. **扫跨时钟域（CDC）**：随机错误最典型来源。用 **Spyglass CDC / Vivado CDC 分析**扫未同步的跨域信号、亚稳态；重点查：单比特快慢域是否打拍、多比特是否握手/格雷码、异步 FIFO 空满是否保守。
3. **查复位与时钟**：
   - 复位：确认**异步复位、同步释放**；查复位树偏斜、漏复位模块、复位时序（是否在时钟建立后释放）；
   - 时钟：PLL/MMCM lock 是否稳定、有无时钟毛刺/切换、门控时钟。
4. **仿真复现**：抓取实际激励写 testbench；加 **SVA 断言**监控协议/时序违例；跑随机 seed 回归。
5. **现场留痕**：出错瞬间把关键状态/计数值/时间戳锁进**错误快照寄存器**，事后经接口读出，定位是哪一拍出问题。
6. **二分隔离**：把数据通路/控制通路、可疑模块逐个屏蔽，缩小范围。

**工具清单**：Vivado **ILA / VIO / IBERT**、VCS/XSim + SVA、**Spyglass CDC**、逻辑分析仪、Xilinx Debug Hub。

**9. 编程题：0~255 计数器，有效时计数、无效保持，255→0 时输出一个时钟周期的溢出脉冲（⭐⭐⭐⭐⭐）**

**知识点**：`计数器`、`Verilog`

**答案**：

```verilog
module cnt_ovf (
    input  clk,
    input  rst_n,
    input  en,            // 有效计数，无效保持
    output reg [7:0] cnt, // 0~255
    output reg ovf        // 255→0 那一拍，输出一个周期高电平
);
    always @(posedge clk or negedge rst_n)
        if (!rst_n) begin
            cnt <= 8'd0;
            ovf <= 1'b0;
        end
        else if (en) begin
            cnt <= cnt + 1'b1;
            ovf <= (cnt == 8'd255);   // 本拍 cnt 由 255 变 0，输出溢出脉冲
        end
        else begin
            cnt <= cnt;               // en 无效：保持
            ovf <= 1'b0;
        end
endmodule
```

**解析**：
- **计数**：`en` 为 1 时 `cnt <= cnt+1`，0~255 循环；`en` 为 0 时 `cnt <= cnt` 保持。
- **溢出脉冲**：`ovf <= (cnt==255)`——当本拍旧值 cnt=255 且 en=1 时，这一拍 cnt 变为 0、ovf 变为 1；下一拍 cnt=0 时 `ovf<=0`。所以 `ovf` 恰好高一个时钟周期，且正是在 255→0 跳变后的那一拍。
- **边界**：复位后 cnt=0 不立即输出脉冲；en 保持有效时每 256 拍出一次溢出。
- 已用仿真验证：`ovf` 只在 255→0 那一拍为高，宽恰为 1 个时钟周期。

### 2.8 复旦微

**考查方向**：亚稳态/CDC、FPGA 架构资源、硬件电路基础（上拉电阻）、时钟资源、时序计算（$f_{max}$、有效 setup/hold）。

> 以下 7 题为面试/笔试回忆整理。第 5、6 题原数据记不全，已按考点自出例题还原考法。题面参数对应：$T_{set}=t_{su}$（建立时间）、$T_h=t_h$（保持时间）、$T_{offset}/T_{skew}$=时钟偏斜。

**1. 什么是 FPGA 的亚稳态？为什么会产生亚稳态？（⭐⭐⭐⭐）**

**知识点**：`亚稳态`、`CDC`

**答案**：
- **是什么**：触发器的输出在时钟沿后**无法在规定时间内稳定到 0 或 1**，停留在中间电平或来回振荡，最终**随机**收敛（收敛时间不可预测）。严格说亚稳态是触发器的普遍现象，不限 FPGA。
- **为什么**：输入数据在时钟沿附近的**建立/保持窗口**内跳变 → 触发器内部正反馈来不及完成"0 还是 1"的判决 → 进入两个稳态之间的不确定区。**本质是违反了 $t_{su}/t_h$**（见第 7 题）。
- **典型场景**：跨时钟域传输（最常考）、异步信号直接进同步逻辑、复位释放时刻。
- **危害**：不定值向后传播——后级可能采到 0/1/振荡值，甚至不同后级采到不同值。
- **解决**：两级同步器（打两拍给收敛时间）、格雷码、异步 FIFO、握手——只能降低概率、不能根治，用 $MTBF$ 衡量。

展开见 [[FPGA/FPGA校招面试八股.md|八股]] 4.1 节。

**2. FPGA 的内部资源有哪些？（⭐⭐⭐）**

**知识点**：`FPGA 架构`

**答案**（按六类记）：

| 类别 | 资源 | 作用 |
|------|------|------|
| 可编程逻辑 | LUT + FF（触发器）+ 进位链（组成 SLICE/CLB） | LUT 查表实现组合逻辑，FF 实现时序逻辑 |
| 存储 | BRAM、分布式 RAM | 大容量块存储 / 小容量异步读存储 |
| 运算 | DSP48 | 乘法 + 累加，滤波、FFT |
| 时钟 | PLL/MMCM + 全局时钟网络 BUFG | 倍频/分频/移相、低偏斜分发时钟 |
| IO | IOB、多种电平标准、DDR、SerDes | 与外部芯片通信 |
| 布线 | 可编程互连（走线 + 开关盒） | 把以上资源连起来——"可编程"的关键 |

（视型号还有硬核：DDR 控制器、PCIe、以太网 MAC、ARM 核等。）展开见 [[FPGA/FPGA校招面试八股.md|八股]] 1.2 节。

**3. 上拉电阻的作用和用途？（⭐⭐⭐）**

**知识点**：`硬件基础`

**答案**（作用，按重要性排）：
1. **确定默认电平**：把悬空/高阻节点箝位到高电平——CMOS 输入不能悬空，否则电平不定、易受干扰；
2. **配合开漏（OD）/开集输出**：开漏只能拉低、不能拉高，输出高电平全靠外部上拉提供；
3. **实现"线与"**：多个开漏输出共接一条线，任一拉低则整线为低——用于共享中断、总线仲裁；
4. **改善上升沿**：与线路电容构成 RC 充电，阻值越小上升沿越快；
5. **限流**：开漏拉低时灌电流 $I=V/R$ 由电阻限制。

**用途**：I2C 的 SDA/SCL（必须上拉）、开漏复位/中断、按键输入（另一端接地）、三态总线防浮空、未用引脚处理、电平转换。

**阻值**：常用 4.7k / 10kΩ——太小功耗大，太大上升沿慢且抗扰差。

**4. FPGA 中的全局时钟网络有哪些优点和作用？（⭐⭐⭐⭐）**

**知识点**：`时钟资源`

**答案**：
**作用**：把时钟经**专用树状布线**低偏斜地送到全芯片触发器，让同一时钟域内所有 FF（触发器）**几乎同时**收到时钟沿。

**优点**：
- **skew 极小、jitter 低**：专用等长缓冲树，时序容易收敛；
- **高扇出、驱动强**：一个 BUFG 可驱动成千上万个 FF，不用手动复制；
- **不占普通布线/逻辑资源**：专用网络，不与数据路径抢走线；
- **延迟可预测**：时序分析简单、$f_{max}$ 更高；还支持时钟使能、BUFGMUX 无毛刺切换。
- **注意**：数量有限（专用稀缺资源），滥用会报错——非全局时钟可用区域时钟/普通布线降级处理。

**反例**：时钟走普通布线 → 延迟大且不可控、skew 大 → 时序无法收敛。展开见 [[FPGA/FPGA校招面试八股.md|八股]] 3.2 节。

**5. 例题：算时钟最高频率（$f_{max}$）（⭐⭐⭐⭐⭐）**

**知识点**：`setup/hold`、`时序计算`

> 原题数据记不全，自出两问还原考法。符号表见本题集 2.7 第 1 题。

**例题 1（无偏斜）**：两级 FF（触发器）之间组合逻辑最大延迟 6ns，$t_{co}=1\text{ns}$，$t_{su}=1\text{ns}$，忽略偏斜，求 $f_{max}$。

$$T_{min} = t_{co} + t_{comb} + t_{su} = 1+6+1 = 8\text{ns} \quad\Rightarrow\quad f_{max} = \frac{1}{8\text{ns}} = 125\text{MHz}$$

**例题 2（含偏斜，高频考法）**：$t_{co}=0.5\text{ns}$，$t_{comb,max}=4.4\text{ns}$，$t_{comb,min}=1\text{ns}$，$t_{su}=0.6\text{ns}$，$t_h=0.4\text{ns}$；**捕获端时钟比发送端晚到** $t_{skew}=0.5\text{ns}$。求有效建立/保持时间与 $f_{max}$。

- 有效 $t_{su} = 0.6 - 0.5 = 0.1\text{ns}$ → $T_{min} = 0.5+4.4+0.1 = 5.0\text{ns}$ → $f_{max} = 200\text{MHz}$；
- 保持检查：数据最快到达 $t_{co}+t_{comb,min} = 0.5+1 = 1.5\text{ns}$ ≥ 有效 $t_h = 0.4+0.5 = 0.9\text{ns}$ ✓ 不违例；
- **变体**：若捕获端**早到** 0.5ns → $T_{min} = 0.5+4.4+0.6+0.5 = 6.0\text{ns}$ → $166.7\text{MHz}$——**偏斜方向决定帮不帮忙**。

**6. 例题：算有效的 $t_{su}$ 和 $t_h$（⭐⭐⭐⭐）**

**知识点**：`时钟偏斜`、`有效建立/保持`

**结论**（定义 $t_{skew}$ = **捕获端时钟沿 − 发送端时钟沿**，晚到为正）：

$$t_{su,eff} = t_{su} - t_{skew}, \qquad t_{h,eff} = t_h + t_{skew}$$

**怎么理解**：捕获端时钟晚到 $\Delta$，数据相当于"多跑了 $\Delta$"才被采样——**建立要求放松 $\Delta$（$-t_{skew}$），保持要求却收紧 $\Delta$（$+t_{skew}$）**，两者此消彼长。

**例题**：$t_{su}=0.6\text{ns}$、$t_h=0.4\text{ns}$：
- 捕获端**晚到** 0.5ns：有效 $t_{su} = 0.1\text{ns}$，有效 $t_h = 0.9\text{ns}$；
- 捕获端**早到** 0.5ns：有效 $t_{su} = 1.1\text{ns}$，有效 $t_h = -0.1\text{ns}$（按 0 看，保持反而宽松）。

**保守口径**：偏斜方向不确定时取最坏值——$t_{su}+|t_{skew}|$、$t_h+|t_{skew}|$（2.7 第 1 题公式中 skew 直接进余量，就是此口径）。不同教材对偏斜方向的定义可能相反，做题先看清符号约定。

**7. 什么是建立时间和保持时间？不满足会怎样？（⭐⭐⭐⭐）**

**知识点**：`setup/hold`

**答案**：
- **建立时间 $t_{su}$**：时钟沿**之前**，数据必须提前稳定的最短时间——"不许迟到"；
- **保持时间 $t_h$**：时钟沿**之后**，数据必须继续保持稳定的最短时间——"不许早退"；
- **来源**：触发器内部主从锁存器开门/关门、正反馈判决都需要时间，所以沿附近的窗口内数据不能动；
- **不满足的后果**：都进入**亚稳态**（第 1 题）。区别：违反 $t_{su}$ → **降频能缓解**（数据到得太晚）；违反 $t_h$ → **与频率无关，降频也没用**（数据变得太早）。

展开（含修复手段）见本题集 2.7 第 2 题、[[FPGA/FPGA校招面试八股.md|八股]] 5.1 节。

### 2.9 九州集团

**考查方向**：Verilog 编程（模块实例化与复用、参数化设计）、分频器。

> 以下 2 道为笔试编程题回忆整理。

**1. 用半加器搭全加器（⭐⭐⭐⭐）**

**知识点**：`Verilog`、`模块实例化`

**题干**：已知半加器模块（输入 A、B，输出 $S = A \oplus B$、$C = A \& B$），用它组成全加器（输入 A、B、Ci，输出 So、Co）。

**答案**：**两个半加器 + 一个或门**——先把 A、B 半加，再把"部分和"与 Ci 半加，两个进位相或：

```verilog
module full_adder(
    input  A, B, Ci,
    output So, Co
);
    wire s1, c1, c2;

    half_adder u_ha1 ( .A(A),  .B(B),  .S(s1), .C(c1) );  // 先加 A + B
    half_adder u_ha2 ( .A(s1), .B(Ci), .S(So), .C(c2) );  // 部分和再加 Ci

    assign Co = c1 | c2;   // 两次加法任一出进位，最终就进位
endmodule
```

**解析（为什么这么接）**：全加器的本质是"三个 1 位数相加"，拆成两步：
1. **HA1 算 $A+B$**：部分和 $s_1 = A \oplus B$，进位 $c_1 = A \& B$；
2. **HA2 算 $s_1 + C_i$**：结果 $S_o = s_1 \oplus C_i = A \oplus B \oplus C_i$ ✓；进位 $c_2 = s_1 \& C_i = (A \oplus B) \cdot C_i$；
3. **最终进位**：两次加法"任意一次进了位"就该进位 → $C_o = c_1 | c_2 = AB + (A \oplus B)C_i$ ✓（进位即三输入多数函数）。

验算 $A=B=C_i=1$：$s_1=0$、$c_1=1$ → $S_o = 0\oplus 1 = 1$、$c_2=0$ → $C_o=1$，即 $1+1+1 = 11$ ✓。

**答题要点**：模块例化按名连接端口；不会做时从"**把复杂运算拆成两次简单运算**"角度想——全加 = 半加两次 + 进位合并。

**2. 补全任意奇数分频器（⭐⭐⭐⭐⭐）**

**知识点**：`分频`、`奇数分频`、`参数化设计`

**题干**：补全模块：`parameter div = 9` 可自定义（奇数），输入 clk、rst_n，输出 clkout。

**答案**：**双沿计数 + 错半拍相或**（50% 占空比）：

```verilog
module odd_div #(parameter div = 9)(
    input  clk,
    input  rst_n,
    output clkout
);
    localparam integer W    = $clog2(div);      // 计数位宽（div=9 → 4 位）
    localparam integer HALF = (div - 1) / 2;

    reg [W-1:0] cnt_p, cnt_n;
    reg clk_p, clk_n;

    // 上升沿：计数 + 产生 clk_p
    always @(posedge clk or negedge rst_n) begin
        if (!rst_n)              cnt_p <= 0;
        else if (cnt_p == div-1) cnt_p <= 0;
        else                     cnt_p <= cnt_p + 1'b1;
    end
    always @(posedge clk or negedge rst_n) begin
        if (!rst_n)              clk_p <= 1'b0;
        else if (cnt_p == HALF)  clk_p <= 1'b1;
        else if (cnt_p == div-1) clk_p <= 1'b0;
    end

    // 下降沿：计数 + 产生 clk_n
    always @(negedge clk or negedge rst_n) begin
        if (!rst_n)              cnt_n <= 0;
        else if (cnt_n == div-1) cnt_n <= 0;
        else                     cnt_n <= cnt_n + 1'b1;
    end
    always @(negedge clk or negedge rst_n) begin
        if (!rst_n)              clk_n <= 1'b0;
        else if (cnt_n == HALF)  clk_n <= 1'b1;
        else if (cnt_n == div-1) clk_n <= 1'b0;
    end

    assign clkout = clk_p | clk_n;   // 两波形错开半拍，相或 → 50% 占空比
endmodule
```

**解析**：
- 难点：高电平要 $div/2 = 4.5$ 个周期——**单边沿触发做不出"半拍"**，所以两份计数器分别用上升沿/下降沿触发，两份波形错开半个周期；
- 每份信号高电平 $(div-1)/2 = 4$ 拍。以 div=9 为例：clk_p 高 [5T, 9T)、clk_n 高 [5.5T, 9.5T)，相或后**高 4.5T、低 4.5T、周期 9T** ✓；
- ⚠️ 别照抄 [[FPGA/FPGA校招面试八股.md|八股]] 8.3 节的 `(cnt==0)|(cnt==0)` 写法——那只对 div=3 成立；参数化后要改成"`cnt==HALF` 置位、`cnt==div-1` 清位"；
- 细节：div 需为奇数且 ≥3；计数位宽用 `$clog2(div)`；实际工程里输出时钟建议过 BUFG 上全局时钟网络。

4. **代码题一定要手写跑通**：分频/序列检测/FIFO 这类，面试官常现场改题。
