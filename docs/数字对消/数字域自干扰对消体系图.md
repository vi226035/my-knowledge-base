# 数字域自干扰对消体系

数字域自干扰对消技术的完整体系分类图。

## 体系结构

该思维导图涵盖六大分支：

| 分支 | 内容 |
|------|------|
| **自适应滤波算法** | LMS → NLMS → RLS → AP → VSSAP，步长因子权衡收敛速度与稳态误差 |
| **信道建模** | 辅助信道对消、线性对消、非线性对消（PA 非线性效应） |
| **功放模型** | 无记忆（Saleh/Ghorbani/多项式/Rapp）+ 有记忆（Volterra/MP/多盒模型） |
| **深度学习** | DNN、CDNN 端到端对消 |
| **空域自干扰对消** | 被动（环形器/天线极化）+ 主动（波束形成/交叉极化） |
| **射频域自干扰对消** | 直接耦合架构 + 数字辅助架构 |
| **功放输出成分** | DC、基波、谐波（2f/3f）、互调（IMD2/IMD3） |
