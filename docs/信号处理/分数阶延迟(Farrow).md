# 分数阶延迟滤波器（Farrow 结构）

分数阶延迟滤波器（Fractional Delay Filter）是数字信号处理中实现**非整数样本延迟**的核心工具。Farrow 结构是其最高效的实现形式之一，由 **C.W. Farrow** 于 1988 年提出，广泛应用于**定时同步、采样率转换、波束成形**等领域。

---

## 一、问题背景：为什么需要分数延迟？

在离散时间系统中，信号只在整数时刻被采样。但实际应用中经常需要**非整数样本的延迟**：

- **定时恢复**：接收机需要在符号边界的精确时刻采样，但该时刻可能落在两个采样点之间
- **采样率转换**：将 44.1 kHz 音频转换为 48 kHz，需要任意比例的重采样
- **波束成形**：天线阵列中不同阵元的信号延迟可能是非整数的
- **回声消除**：声学回声的延迟时间通常不是采样周期的整数倍

**核心问题**：如何在不增加采样率的前提下，实现任意精度的延迟？

---

## 二、理想分数延迟滤波器

### 2.1 理想频率响应

理想的分数延迟滤波器对信号施加纯延迟 $D$（可以是任意实数），其频率响应为：

$$H_{\text{ideal}}(e^{j\omega}) = e^{-j\omega D}$$

其中 $D = m + \mu$，$m$ 为整数部分，$\mu \in [0, 1)$ 为分数部分。

### 2.2 理想脉冲响应

对理想频率响应做逆傅里叶变换，得到理想脉冲响应：

$$h_{\text{ideal}}(n) = \text{sinc}(n - D) = \frac{\sin[\pi(n - D)]}{\pi(n - D)}$$

**问题**：理想 sinc 函数是**无限长**的，实际中必须截断，导致：
- 吉布斯现象（Gibbs phenomenon）
- 频率响应在截止频率处出现振铃
- 需要窗函数平滑截断

---

## 三、多项式插值方法

为了避免直接设计无限长的 sinc 滤波器，多项式插值提供了一种更实用的方法。

### 3.1 基本思想

将分数延迟滤波器的系数表示为延迟参数 $\mu$ 的多项式：

$$h(n, \mu) = \sum_{k=0}^{N} c_k(n) \mu^k$$

其中：
- $N$ 为多项式阶数
- $c_k(n)$ 为固定系数（与 $\mu$ 无关）
- $\mu$ 为可调的分数延迟参数

**关键优势**：只需改变 $\mu$，即可实时调整延迟，无需重新计算滤波器系数。

### 3.2 常用多项式类型

| 多项式类型 | 特点 | 适用场景 |
|:---|:---|:---|
| **Lagrange 插值** | 最大平坦（Maximally Flat），低频精度高 | 对低频精度要求高的场景 |
| **最小二乘多项式** | 整体误差最小，带宽更大 | 宽带信号处理 |
| **三次样条** | 平滑性好，计算简单 | 实时性要求高的场景 |
| **Thiran 全通** | 全通特性，幅度响应恒为 1 | 相位敏感应用 |

## 四、Lagrange 插值详解

Lagrange 插值是最经典的多项式插值方法，具有**最大平坦**特性。

### 4.1 Lagrange 插值公式

给定 $N+1$ 个采样点 $x(n-N_1), x(n-N_1+1), \ldots, x(n+N_2)$，Lagrange 插值在点 $n + \mu$ 处的值为：

$$y(n) = \sum_{k=-N_1}^{N_2} x(n-k) \cdot L_k(\mu)$$

其中 Lagrange 基函数为：

$$L_k(\mu) = \prod_{\substack{i=-N_1 \\ i \neq k}}^{N_2} \frac{\mu - i}{k - i}$$

### 4.2 三阶 Lagrange 插值示例

对于三阶插值（$N=3$），使用 4 个采样点 $x(n-1), x(n), x(n+1), x(n+2)$：

$$L_{-1}(\mu) = \frac{\mu(\mu-1)(\mu-2)}{(-1)(-2)(-3)} = -\frac{\mu(\mu-1)(\mu-2)}{6}$$

$$L_0(\mu) = \frac{(\mu+1)(\mu-1)(\mu-2)}{(1)(-1)(-2)} = \frac{(\mu+1)(\mu-1)(\mu-2)}{2}$$

$$L_1(\mu) = \frac{(\mu+1)\mu(\mu-2)}{(2)(1)(-1)} = -\frac{(\mu+1)\mu(\mu-2)}{2}$$

$$L_2(\mu) = \frac{(\mu+1)\mu(\mu-1)}{(3)(2)(1)} = \frac{(\mu+1)\mu(\mu-1)}{6}$$

### 4.3 Lagrange 插值的频率响应特性

- **低频**：幅度响应非常平坦，接近理想延迟
- **高频**：幅度衰减明显，相位误差增大
- **阶数越高**：平坦带宽越大，但计算复杂度增加

## 五、Farrow 结构

### 5.1 核心思想

Farrow 结构的核心是将多项式插值滤波器分解为**固定子滤波器**和**可变参数**的组合：

$$y(n) = \sum_{k=0}^{N} \mu^k \cdot \underbrace{\left[\sum_{m} c_k(m) x(n-m)\right]}_{v_k(n)}$$

其中：
- $v_k(n) = \sum_{m} c_k(m) x(n-m)$ 是第 $k$ 个子滤波器的输出
- $c_k(m)$ 是固定的子滤波器系数
- $\mu$ 是可调的分数延迟参数

### 5.2 Farrow 结构框图

```
输入 x(n)
    │
    ├──────────────┬──────────────┬──────────────┬──────────────┐
    │              │              │              │              │
    ▼              ▼              ▼              ▼              ▼
  h₀(z)          h₁(z)          h₂(z)          h₃(z)        h_N(z)
    │              │              │              │              │
    ▼              ▼              ▼              ▼              ▼
  v₀(n)          v₁(n)          v₂(n)          v₃(n)        v_N(n)
    │              │              │              │              │
    │              │              │              │              │
    ▼              ▼              ▼              ▼              ▼
   ×1            ×μ             ×μ²            ×μ³           ×μ^N
    │              │              │              │              │
    └──────────────┴──────────────┴──────────────┴──────────────┘
                                │
                                ▼
                              Σ (求和)
                                │
                                ▼
                            输出 y(n)
```

**关键特性**：
- 子滤波器 $h_k(z)$ 的系数是**固定的**，只需设计一次
- 只有 $\mu$ 的幂次乘法是**可变的**
- 可以逐样本改变 $\mu$，实现**时变延迟**

### 5.3 计算复杂度

对于 $N$ 阶 Farrow 结构，每个输出样本需要：
- $N+1$ 个子滤波器卷积：$(N+1) \times L$ 次乘法（$L$ 为子滤波器长度）
- $N$ 次 $\mu$ 的幂次计算（可优化为递推乘法）
- $N+1$ 次最终求和

**优化技巧**：使用 Horner 规则减少 $\mu$ 的幂次计算：

$$y = v_0 + \mu(v_1 + \mu(v_2 + \mu v_3))$$

只需 3 次乘法，而非计算 $\mu, \mu^2, \mu^3$ 的多次乘法。

## 六、子滤波器设计

### 6.1 从 Lagrange 系数提取子滤波器

将 Lagrange 基函数展开为 $\mu$ 的多项式：

$$L_k(\mu) = \sum_{i=0}^{N} a_{k,i} \mu^i$$

则第 $i$ 个子滤波器的系数为：

$$c_i(m) = a_{m,i}, \quad m = -N_1, -N_1+1, \ldots, N_2$$

### 6.2 三阶 Farrow 子滤波器示例

对于三阶 Lagrange 插值，展开基函数后得到子滤波器系数：

| 子滤波器 | 系数 $c_k(-1)$ | $c_k(0)$ | $c_k(1)$ | $c_k(2)$ |
|:---|:---:|:---:|:---:|:---:|
| $h_0(z)$ | 0 | 1 | 0 | 0 |
| $h_1(z)$ | $-1/6$ | $-1/2$ | $1$ | $-1/3$ |
| $h_2(z)$ | $1/2$ | $-1$ | $1/2$ | $0$ |
| $h_3(z)$ | $-1/6$ | $1/2$ | $-1/2$ | $1/6$ |

### 6.3 最小二乘法设计

除了 Lagrange 插值，还可以用**最小二乘法**设计子滤波器，使得在指定频带内整体误差最小：

$$\min_{c_k} \int_{0}^{\omega_p} |H(e^{j\omega}, \mu) - e^{-j\omega D}|^2 d\omega$$

最小二乘法设计的 Farrow 滤波器具有：
- 更大的有效带宽
- 更小的整体误差
- 但低频平坦度不如 Lagrange

## 七、与其他插值方法的比较

### 7.1 线性插值（一阶）

$$y(n) = (1-\mu) x(n) + \mu x(n+1)$$

- **优点**：极其简单，只需 1 次乘法
- **缺点**：高频衰减严重，只适用于低精度场景

### 7.2 三次样条插值

使用分段三次多项式，保证一阶和二阶导数连续：

$$y(n) = a_0 + a_1 \mu + a_2 \mu^2 + a_3 \mu^3$$

- **优点**：平滑性好，计算效率较高
- **缺点**：需要求解全局方程组，不适合实时变延迟

### 7.3 sinc 插值（加窗）

$$h(n) = \text{sinc}(n - D) \cdot w(n)$$

其中 $w(n)$ 为窗函数（如 Hamming、Kaiser）。

- **优点**：频率响应接近理想
- **缺点**：滤波器长度长，计算量大，不适合变延迟

### 7.4 综合对比

| 方法 | 计算复杂度 | 频率响应 | 变延迟支持 | 适用场景 |
|:---|:---:|:---:|:---:|:---|
| 线性插值 | 极低 | 差 | 好 | 低精度快速原型 |
| Lagrange Farrow | 中 | 好（低频） | 极好 | 定时同步、波束成形 |
| 最小二乘 Farrow | 中 | 很好（宽带） | 极好 | 宽带信号处理 |
| 三次样条 | 中 | 好 | 一般 | 离线插值 |
| 加窗 sinc | 高 | 极好 | 差 | 固定延迟高精度 |

## 八、应用场景

### 8.1 定时恢复（Timing Recovery）

在数字通信接收机中，符号定时误差会导致采样点偏离最佳位置。Farrow 滤波器用于：

1. **Gardner 定时误差检测器**：检测符号定时误差
2. **环路滤波器**：平滑误差，生成控制信号
3. **Farrow 插值器**：根据控制信号 $\mu$ 重新采样

```
接收信号 → 匹配滤波 → 定时误差检测 → 环路滤波 → μ 控制
                                                    ↓
                          Farrow 插值器 ← 调整延迟 ←─┘
                                ↓
                          符号判决
```

### 8.2 采样率转换（Sample Rate Conversion）

将采样率从 $f_{s1}$ 转换为 $f_{s2}$，转换比为 $R = f_{s2}/f_{s1}$（可以是任意实数）。

**步骤**：
1. 计算输出样本对应的输入时间位置：$t_{\text{out}} = n \cdot T_{s2}$
2. 分解为整数和分数部分：$t_{\text{out}} = (m + \mu) \cdot T_{s1}$
3. 使用 Farrow 滤波器在 $m + \mu$ 处插值

**优势**：无需预计算滤波器系数，支持任意比例转换。

### 8.3 波束成形（Beamforming）

天线阵列中，不同阵元接收到的信号存在**非整数样本的时延差**。Farrow 滤波器用于：

- 精确对齐各阵元信号
- 实现宽带波束成形
- 支持动态波束扫描

### 8.4 回声消除（Echo Cancellation）

声学回声的延迟时间通常不是采样周期的整数倍。Farrow 滤波器用于：

- 精确估计和补偿非整数延迟
- 自适应更新延迟参数

## 九、FPGA 实现考虑

### 9.1 硬件架构优化

**流水线设计**：
- 子滤波器卷积可以并行计算
- $\mu$ 的幂次计算使用递推乘法
- 最终求和树使用流水线加法器

**系数存储**：
- 子滤波器系数是固定的，可以用 ROM 存储
- 对于多通道应用，可以共享子滤波器

### 9.2 定点数设计

**位宽规划**：
- 输入信号：16~24 bit
- 子滤波器系数：18~24 bit（利用 FPGA 的 DSP48 块）
- $\mu$ 参数：16~24 bit
- 中间结果：需要保护位防止溢出
- 输出信号：与输入相同位宽，截断或舍入

**量化误差分析**：
- 系数量化会引入幅度误差
- $\mu$ 的量化会引入延迟误差
- 需要使用足够的位宽保证精度

### 9.3 资源消耗估算

对于三阶 Farrow 结构（4 个子滤波器，每个长度 4）：
- 乘法器：$4 \times 4 = 16$ 个（子滤波器）+ 3 个（Horner 规则）= 19 个
- 加法器：类似数量
- 存储：16 个系数（可用 DSP48 的内部寄存器）

**典型 FPGA 资源**（Xilinx Artix-7）：
- DSP48 块：19 个
- 寄存器：约 200 个
- LUT：约 300 个
- 最大时钟频率：200~300 MHz

## 十、设计实例：三阶 Lagrange Farrow 滤波器

### 10.1 MATLAB 代码

```matlab
% 三阶 Lagrange Farrow 滤波器设计
N = 3;                    % 多项式阶数
L = 4;                    % 子滤波器长度
mu = 0.37;                % 分数延迟参数

% 子滤波器系数矩阵（行对应子滤波器，列对应抽头）
C = [
    0,     1,     0,     0;      % h0: 整数延迟
   -1/6,  -1/2,   1,   -1/3;    % h1: 一阶项
    1/2,  -1,    1/2,   0;      % h2: 二阶项
   -1/6,   1/2,  -1/2,  1/6     % h3: 三阶项
];

% 输入信号
n = 0:100;
x = sin(2*pi*0.1*n) + 0.5*sin(2*pi*0.3*n);

% 计算子滤波器输出
v = zeros(N+1, length(x));
for k = 1:N+1
    v(k,:) = filter(C(k,:), 1, x);
end

% 使用 Horner 规则计算输出
y = v(1,:);
for k = 2:N+1
    y = y + mu^(k-1) * v(k,:);
end

% 绘图
figure;
plot(n, x, 'b-', n, y, 'r--');
legend('原始信号', '延迟后信号');
title(sprintf('三阶 Lagrange Farrow 滤波器，延迟 = %.2f 样本', mu));
xlabel('样本索引'); ylabel('幅度');
```

### 10.2 Verilog 代码框架

```verilog
module farrow_filter_3rd (
    input  wire        clk,
    input  wire        rst,
    input  wire [15:0] x_in,      // 输入信号（16 bit）
    input  wire [15:0] mu,        // 分数延迟参数（0.16 定点）
    output wire [15:0] y_out      // 输出信号
);

    // 子滤波器系数（18 bit 定点）
    localparam C0 = 18'sd0;       // h0: [0, 1, 0, 0]
    localparam C1_0 = -18'sd10923; // -1/6
    localparam C1_1 = -18'sd32768; // -1/2
    localparam C1_2 = 18'sd65536;  // 1
    localparam C1_3 = -18'sd21845; // -1/3
    // ... 其他系数

    // 输入移位寄存器
    reg [15:0] x_reg [0:3];
    always @(posedge clk) begin
        if (rst) begin
            x_reg[0] <= 16'sd0;
            x_reg[1] <= 16'sd0;
            x_reg[2] <= 16'sd0;
            x_reg[3] <= 16'sd0;
        end else begin
            x_reg[3] <= x_reg[2];
            x_reg[2] <= x_reg[1];
            x_reg[1] <= x_reg[0];
            x_reg[0] <= x_in;
        end
    end

    // 子滤波器输出（使用 DSP48 乘法器）
    wire [33:0] v0, v1, v2, v3;
    assign v0 = x_reg[1];  // h0 只有 c(1) = 1
    
    // h1: -1/6*x[n+1] - 1/2*x[n] + 1*x[n-1] - 1/3*x[n-2]
    assign v1 = C1_0 * x_reg[0] + C1_1 * x_reg[1] 
              + C1_2 * x_reg[2] + C1_3 * x_reg[3];
    
    // ... h2, h3 类似

    // Horner 规则计算输出
    // y = v0 + mu*(v1 + mu*(v2 + mu*v3))
    wire [49:0] temp1 = v3 * mu;
    wire [49:0] temp2 = (v2 + temp1) * mu;
    wire [49:0] temp3 = (v1 + temp2) * mu;
    wire [49:0] y_full = v0 + temp3;

    // 截断到 16 bit（需要根据实际位宽调整）
    assign y_out = y_full[31:16];

endmodule
```

## 十一、进阶主题

### 11.1 高阶 Farrow 结构

增加多项式阶数 $N$ 可以：
- 提高插值精度
- 扩大有效带宽
- 但增加计算复杂度

**典型选择**：$N = 3$（三阶）或 $N = 4$（四阶），在精度和复杂度之间取得平衡。

### 11.2 改进的 Farrow 结构

**对称 Farrow 结构**：利用子滤波器的对称性减少计算量。

**分段多项式 Farrow**：将 $\mu \in [0,1)$ 分成多段，每段使用低阶多项式，提高精度。

### 11.3 与多相滤波器的关系

Farrow 结构可以看作**连续参数化的多相滤波器**：
- 多相滤波器：$\mu$ 只能取离散值（如 $0, 1/M, 2/M, \ldots$）
- Farrow 滤波器：$\mu$ 可以取连续值
